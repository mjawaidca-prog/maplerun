Auth & routing guards
⦿
All app routes (/app, /employees/*, /payroll/*, /reports/*, /company) redirect to /sign-in when no session.
⦿
After sign-in, if session has no company yet → redirect to /onboarding; else → /app.
⦿
/onboarding is only reachable with a session and no company. With a company, redirect → /app.
⦿
ROE routes (/reports/roe/*) require Accountant plan. Growth/Solo → show upgrade modal overlay on /reports.
Auto-redirects after actions
⤷
Onboarding submit (create company) → redirect /app.
⤷
Add employee submit → redirect /employees.
⤷
Wizard step 3 (finalize) → auto-redirect /payroll after ~2 s, or user clicks "View pay run" → /payroll/[id].
⤷
Timesheet import (confirm) → fills hours in timesheet entry, redirects /payroll/timesheet.
Wizard state machine
→
Step 1 (input) — gross amounts entered, "Calculate deductions" calls engine → advances to Step 2.
→
Step 2 (preview) — show deductions, warnings. "Back" → Step 1 (preserves inputs). "Finalize" → Step 3.
→
Step 3 (success) — read-only confirmation. Wizard state cleared. No "Back" here.
⚠
State (step, inputs, preview data) should survive page refresh — store in sessionStorage keyed by pay group + period.
Timesheet & payroll entry points
→
Salaried staff: "Run payroll" → Wizard Step 1 (enter gross amounts directly).
→
Hourly staff: "Timesheet" → Timesheet entry (hours grid) → "Calculate deductions" → Wizard Step 2 (skip step 1; hours already computed gross).
→
Timesheet import: CSV → column map → review → populates Timesheet entry → same path as above.
ℹ
A pay group may be salary (uses wizard step 1) or hourly (uses timesheet). Routing branches at "Run payroll" based on pay group type.
