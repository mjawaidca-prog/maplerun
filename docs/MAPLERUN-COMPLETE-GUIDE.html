Vacation Pay

Per-employee toggle in the wizard with customizable percentage. Default 4% (most provinces for <5 years service). Calculated as Gross × Rate%. Shown on pay stub. Canadian employment standards minimums: 4% → 6% at 5 years (varies by province). Saskatchewan: 3/52 (≈5.77%), Quebec: 4% then 6%.

Hours Tracking

Per-employee hours input (default 75 for biweekly). Stored per pay period. Used for ROE Block 15A (insurable hours). Displayed on pay stubs with calculated hourly rate.

First-time sign-in shows onboarding: company name, workspace slug, default province, pay frequency. Creates company + default pay group.

Section 11
Frequently Asked Questions
Q
How accurate are the tax calculations? All formulas follow CRA T4127. 137 automated tests verify every calculation. Golden tests match PDOC within $0.50.
Q
Does MapleRun file taxes with CRA? No. It calculates amounts and generates reports. You file through your CRA business account.
Q
How do tax tables update each year? New CRA edition → create data files → register → run tests → deploy. Past pay runs keep original rates.
Q
Is my data secure? SIN and bank details are AES-256-GCM encrypted. All connections use SSL. Stripe handles payments (PCI DSS Level 1).
Q
Can I switch plans anytime? Yes. Company → Profile → click any plan button. Changes instantly. Upgrade/downgrade anytime.
Q
What about Quebec? Fully supported: QPP (6.30%), QPIP (0.43%), reduced EI (1.30%), Quebec provincial tax, 16.5% federal abatement.
Q
Can I have multiple companies? Yes. Click "＋ New company" in sidebar. Switch between them using the company switcher.
Q
How do I delete test data? Payroll history → red Delete button on any run. Employee list → trash icon on any row. Confirm to delete permanently.
